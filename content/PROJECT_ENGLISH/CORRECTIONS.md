## 2026-01-07

### 1. Plural/Singular Agreement
❌ "all of thing is so good"
✅ "All of **those** sounds good" / "All of **that** sounds good"

- thing → those/that (여러 옵션 지칭)
- is → sounds (동의할 때 더 자연스러움)

---

### 2. Object Pronoun + Word Choice
❌ "when you correct describe in korean please"
✅ "When you correct **me**, please **explain** in Korean"

- correct 다음에 목적어 "me" 필요
- describe → explain (설명하다)
- please는 문장 중간이 자연스러움

---

### 3. Should + Have + P.P (Past Regret)
❌ "english study context should existed"
✅ "English study context **should have existed**"

- should existed ❌
- should + 동사원형 (현재/미래)
- should have + p.p (과거 후회)

---

### 4. Question Form + Spelling
❌ "project_english alreay exist??"
✅ "**Does** PROJECT_English **already** exist?"

- 질문: Does + 주어 + 동사원형
- alreay → already (스펠링)

---

### 5. When Clause = Present Tense
❌ "when i will connect in phone i say you can say in eng corrections"
✅ "When I connect **on my** phone, I'll ask you to give corrections in English"

- when I will connect → when I connect (when절은 현재시제)
- in phone → on my phone (전치사)
- 어순: corrections in English

## Common Patterns (자주 틀리는 패턴)

| Pattern | Wrong | Correct |
|---------|-------|---------|
| should + verb | should existed | should exist |
| past regret | should existed | should have existed |
| article | to project | to the project |
| 3rd person | it exist | it exists |
| when clause | when I will go | when I go |
| preposition | in phone | on my phone |

---

## Quick Rules

1. **When/If절** → 현재시제로 미래 표현
   - When I **get** home, I **will** call you.

2. **Should** → 동사원형
   - should **be**, should **have been**

3. **Device 전치사** → on
   - on my phone, on the computer

4. **Questions** → 조동사 앞으로
   - Does it work? / Can you help?
