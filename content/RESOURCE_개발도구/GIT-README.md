# Git 문서 가이드

실무에서 유용한 Git 명령어들을 카테고리별로 분류하여 정리했습니다.

## 📁 문서 구조

### 📘 기본 (basics/)
- `setup.md` - Git 초기 설정 및 저장소 생성
- `staging.md` - 스테이징 영역 관리 및 커밋
- `viewing.md` - 히스토리 조회 및 상태 확인

### 🌿 브랜치 관리 (branching/)
- `branch-operations.md` - 브랜치 생성, 전환, 삭제
- `merge-rebase.md` - 머지와 리베이스 전략
- `remote-sync.md` - 원격 저장소 동기화

### 🔄 워크플로우 (workflow/)
- `daily-commands.md` - 일상적인 Git 작업 흐름
- `team-practices.md` - 팀 협업을 위한 베스트 프랙티스
- `commit-conventions.md` - 커밋 메시지 컨벤션

### 🚀 고급 기능 (advanced/)
- `cherry-pick.md` - 체리픽과 선택적 커밋 적용
- `hooks-automation.md` - Git Hooks 설정 및 자동화
- `submodules.md` - 서브모듈 관리
- `performance.md` - 저장소 최적화 및 성능 개선

### 🔧 문제 해결 (troubleshooting/)
- `common-issues.md` - 자주 발생하는 문제와 해결법
- `recovery.md` - 실수 복구 및 데이터 복원
- `conflicts.md` - 충돌 해결 가이드

---

각 카테고리별 상세 문서를 참조하여 상황에 맞는 Git 명령어를 찾아 사용하세요.
