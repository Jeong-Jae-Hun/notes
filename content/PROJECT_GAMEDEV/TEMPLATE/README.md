## 🚀 시작하기

### 필수 조건

- [Unreal Engine 5](https://www.unrealengine.com/)
- [Git](https://git-scm.com/)
- [Git LFS](https://git-lfs.github.com/)

### 설치

```bash
# 레포지토리 클론
git clone git@github.com:Jeong-Jae-Hun/game.git
cd game

# Git LFS 파일 가져오기
git lfs pull

# 언리얼 프로젝트 열기
# .uproject 파일 더블클릭
```
