# 언리얼 Co-op 게임 프로젝트

## 프로젝트 개요

친구와 함께 만드는 언리얼 엔진 멀티플레이어 게임 프로젝트.

## 팀 구성

| 역할 | 담당 | 주요 작업 |
|------|------|----------|
| 프로그래머 | [이름] | 블루프린트, C++, 네트워크 |
| 사운드 디자이너 | [이름] | BGM, SFX, 사운드 시스템 |

## 기본 규칙

- 한국어로 소통
- 커밋 메시지: `타입: 요약` (50자 이내)
  - 예: `feat: 캐릭터 이동 구현`, `fix: 충돌 버그 수정`
- PR은 상대방 리뷰 후 머지

## AI 어시스턴트 활용

### 프로그래머용 프롬프트 예시

```
- "이 블루프린트를 C++로 변환해줘"
- "Replication 설정 방법 알려줘"
- "이 에러 메시지 해결 방법은?"
```

### 사운드 디자이너용 프롬프트 예시

```
- "언리얼에서 사운드 큐 만드는 방법"
- "거리 기반 사운드 감쇠 설정"
- "이 사운드 에셋 임포트가 안 돼"
```

## 폴더 구조

```
프로젝트/
├── .claude/           # AI 설정 (이 파일)
├── docs/              # 문서
│   ├── _CONTEXT.md    # 현재 진행 상황
│   ├── CURRICULUM.md  # 학습 커리큘럼
│   └── *.md           # 기타 가이드
├── Content/           # 언리얼 컨텐츠
│   ├── Blueprints/
│   ├── Audio/
│   └── ...
└── Source/            # C++ 소스
```

## 작업 흐름

1. 작업 시작 전 `docs/_CONTEXT.md` 확인
2. 작업 완료 후 `_CONTEXT.md` 업데이트
3. 주 1회 싱크업 미팅

## 유용한 명령어

```bash
# 변경사항 확인
git status

# 커밋
git add .
git commit -m "feat: 기능 설명"

# 푸시
git push

# 상대방 변경사항 가져오기
git pull
```
