# ADsP 시험 준비 기록 (2025)

데이터분석준전문가(ADsP) 자격증 시험 준비부터 합격까지의 과정을 기록합니다.

## 결과

> [!success] 합격
> - **시험일**: 2025-11-02
> - **준비 기간**: 약 2주 (10/20 ~ 11/01)
> - **일일 학습 시간**: 약 2시간

## 시험 정보

| 항목 | 내용 |
|------|------|
| 자격증 | 데이터분석준전문가 (ADsP) |
| 주관 | 한국데이터산업진흥원 |
| 시험 범위 | 데이터 분석 기초, 통계, R 프로그래밍 |
| 합격 기준 | 60점 이상 + 과목별 40% 이상 |

## 과목별 학습 내용

### 1과목: 데이터 이해

- 데이터의 정의와 특성
- 데이터베이스 기초
- 빅데이터 개념

### 2과목: 데이터 분석 기획

- 분석 과제 정의
- 분석 방법론 (CRISP-DM 등)
- 분석 마스터 플랜

### 3과목: 데이터 분석

- **기초 통계**: 기술통계량, 확률분포, 가설검정
- **상관 분석**: 상관계수 해석, 유의성 검정
- **회귀 분석**: 단순/다중 회귀
- **R 프로그래밍**: 기본 문법, 데이터 처리

## AI 활용 방법

시험 준비 전 과정에서 Claude AI를 적극 활용했습니다.

### 1. 맞춤형 문제 생성

```
입력: 기존 기출문제 PDF + 교재 내용
출력: R 코드/그래프 포함된 새 모의고사 3세트 PDF
```

- 기출문제와 새 문제를 조합한 모의고사 세트 제작
- R 코드, 그래프 등 시각 자료 포함
- 한글 폰트 적용된 PDF로 출력

### 2. 자동 채점 및 분석

```
입력: "3233331331 1121134333 x411414132..." (내 답안)
      "헷갈린 문제: 3번, 4번, 6번..."
출력: 과목별 점수 + 취약 영역 분석 PDF
```

- 답안을 숫자로 입력하면 자동 채점
- 과목별 점수 산출 (합격/불합격 판정)
- 헷갈린 문제 따로 분류해서 분석

### 3. 취약점 추적

| 회차 | 점수 | 취약 영역 |
|------|------|-----------|
| Set 03 | 58.5점 ❌ | 2과목, 3과목 |
| Set 06 | 개선됨 ✅ | 보완 완료 |

- 여러 회차 결과 누적 비교
- 반복적으로 틀리는 유형 식별
- 회차별 성장 추이 확인

### 4. 개념 설명

- 교재 특정 페이지 내용 설명 요청 (예: 229페이지 상관분석)
- 상관계수 해석, 유의성 검정 등 어려운 개념 질문
- R 코드 실습 가이드

### 5. 학습 계획 수립

```
Q: "시험이 11/2인데 진도가 상관분석이야. 어떻게 해야 할까?"
A: 12일 남음 → 1주차 개념정리, 마지막 5일 기출 집중
```

- 남은 기간과 현재 진도 기반 맞춤 계획
- 시간 배분 전략 제안
