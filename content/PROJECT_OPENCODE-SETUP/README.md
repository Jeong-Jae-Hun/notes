# OpenCode 설정 구축

> Created: 2026-01-04

## 개요

OpenCode CLI 도구 설정을 체계적으로 구축하는 프로젝트

## OpenCode란?

- Claude Code의 오픈소스 대안
- Go 기반 터미널 AI 코딩 에이전트
- 다양한 AI 제공자 지원 (Anthropic, OpenAI, Gemini 등)
- TUI 인터페이스 제공

## 현재 상태

- [ ] 초기 설치
- [ ] 기본 설정 구성
- [ ] dotfiles 통합
- [ ] 커맨드 추가

## 관련 경로

- `~/.dotfiles/opencode/` - 설정 원본 (예정)
- `~/.config/opencode/` - 심볼링크 (예정)
- `~/.opencode.json` - 글로벌 설정
