# ADsP 시험 준비 기록 (2025)

데이터분석준전문가(ADsP) 자격증 시험 준비 과정을 기록합니다.

## 시험 정보

- **자격증**: 데이터분석준전문가 (ADsP)
- **주관**: 한국데이터산업진흥원
- **시험 범위**: 데이터 분석 기초, 통계, R 프로그래밍

## 학습 전략

### 기출 중심 학습
- 40회차 기출문제 확보
- 이론보다 기출 풀이에 집중
- 핵심 개념 파악 후 문제 풀이

### 시간 배분
- 하루 약 2시간 투자
- 약 2주간 집중 학습

## 주요 학습 내용

### 1. 상관 분석
- 상관계수 해석 방법
- 통계적 유의성 검정
- R을 활용한 실습

### 2. 기초 통계
- 기술통계량 (평균, 분산, 표준편차)
- 확률분포
- 가설검정

### 3. 데이터 분석 기획
- 분석 과제 정의
- 분석 방법론

## 학습 도구

- **Claude AI**: 문제 생성, 취약점 분석, 개념 설명
- **R**: 통계 실습
- **기출문제집**: 40회차 반복 풀이

## 팁

> [!tip] 효율적인 학습법
> 1. 핵심 개념만 빠르게 파악
> 2. 기출문제 풀면서 부족한 부분 보충
> 3. 틀린 문제 오답 노트 작성
> 4. AI 활용하여 맞춤형 문제 생성
