# Pinterest Pixie 추천시스템 학습 (2025)

Pinterest의 Pixie 추천시스템을 분석하고 학습한 내용을 정리합니다.

## 개요

Pixie는 Pinterest가 2017년에 발표한 추천 시스템으로, **Random Walk** 알고리즘을 기반으로 합니다. 머신러닝을 거의 사용하지 않으면서도 높은 성능을 보여주는 것이 특징입니다.

## 핵심 개념

### Bipartite Graph
Pinterest의 데이터를 그래프로 표현:
- **노드**: 사용자, Pin, Board
- **엣지**: 저장, 리핀 관계

```
사용자 A ──저장──> Pin 1 <──저장── 사용자 B
                    │
                 포함됨
                    ↓
                 Board X
                    │
                 포함됨
                    ↓
                  Pin 2 (추천 후보)
```

### Random Walk
그래프 위를 무작위로 걸어다니며 연결 관계 탐색:

1. 시작점(사용자가 최근 본 Pin)에서 출발
2. 연결된 노드로 무작위 이동
3. 여러 번 반복하여 자주 도착하는 노드 = 추천 아이템

## Pixie의 장점

| 특징 | 설명 |
|------|------|
| 경량 | 복잡한 ML 모델 없이 동작 |
| 빠름 | 실시간 추천 가능 |
| 설명 가능 | 왜 추천됐는지 경로로 설명 |
| 확장성 | 대규모 그래프에서도 효율적 |

## 관련 알고리즘

### Two Tower Model
- 쿼리 타워(사용자)와 아이템 타워 분리
- 임베딩 벡터 유사도로 추천
- Pixie보다 ML 의존도 높음
