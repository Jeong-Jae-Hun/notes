# 2026 — 인프라 심화, 그리고 내 것 만들기

플랫폼 인프라를 더 깊이 다루면서, 회사 밖에서 **내 프로젝트와 홈랩**을 굴리기 시작한 해.

## 한 일

| 영역 | 내용 |
|------|------|
| 인프라 IaC | Pulumi(TypeScript)로 클라우드 인프라를 코드로 관리 |
| 모니터링 | Grafana 대시보드로 서비스 관측 체계 구축 |
| API Gateway | Lua/OpenResty 게이트웨이 — 레이트리밋·인증·캐싱 |
| 다국어 | 번역·다국어 지원 등 글로벌 대응 작업 |

## 회사 밖에서

- **홈랩 인프라**: Proxmox·K8s·Pulumi로 집에 나만의 서버 환경 구축
- **사이드 프로젝트**: 커뮤니티 포털, 공개 노트 블로그(이 사이트) 등
- 문서·지식 관리 시스템(옵시디언 기반) 정비

## 방향

- 실시간 시스템 스페셜리스트 ↔ 테크 리드 사이에서 다음 스텝 고민
- 대외 활동(기술 글쓰기·오픈소스) 넓히기
