# 2025 — 대규모 실시간 서비스 0→1

새 **대규모 실시간 서비스**를 초기 세팅부터 풀스택으로 만든 해. 역할의 무게가 리드급으로 넘어갔다.

## 한 일

| 영역 | 내용 |
|------|------|
| 실시간 시스템 | WebSocket 기반 실시간 기능, Outbox 패턴 기반 이벤트 전파 |
| 스트리밍 인프라 | HLS 스트리밍, Docker, 미디어 서버 |
| 플랫폼 인프라 | API Gateway 인증 미들웨어(Lua/OpenResty) |
| 앱 | React Native 앱 환경·CD 파이프라인(Fastlane) |
| 개발 문화 | 코드 리뷰 대량 수행, 린터 전환, E2E 환경 |
