# 2024 — 통합 인증 시스템 0→1

여러 서비스가 함께 쓰는 **통합 인증 시스템을 처음부터 설계·구축**한 해.

## 한 일

| 영역 | 내용 |
|------|------|
| 통합 인증 | 로그인/회원가입, 세션 관리, OAuth, SNS 로그인, SDK, E2E 테스트까지 인증 전 영역 |
| 구독 시스템 | 가입·해지·갱신 플로우와 위젯·스토어 등 0→1 |
| 관리 도구 | 온보딩·정산·출금·통합 검색 |
| 모바일 앱 | 앱 메이저 업데이트, 플랫폼 대응 |
| 외부 연동 | 외부 플랫폼 로그인 연동 |

## 배운 것

- 인증/세션/OAuth 같은 **보안 민감 시스템의 전체 설계**
- 재사용 가능한 **SDK·컴포넌트 라이브러리** 만들기
- E2E 테스트 도입으로 안정성 확보
