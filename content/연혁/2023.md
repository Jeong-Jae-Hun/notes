# 2023 — 풀스택 본격화

이직한 회사에서 여러 도메인을 오가며 **풀스택 개발자로 자리잡은 해.**

## 한 일

| 영역 | 내용 |
|------|------|
| 오픈 API | 외부 개발자용 API 설계·문서화(OpenAPI)·통합 테스트 환경 구축 |
| 정산 시스템 | 외주 정산 뷰·마이너스 정산 등 0→1 |
| 휴면 계정 | 대량 배치 처리·안내 메일·개인정보 처리 로직 |
| 웹 리뉴얼 | 로그인/마이페이지/리뷰 등 인증·사용자 도메인 |
| 모바일 앱 | React Native 앱(딥링크·플랫폼 대응·앱스토어 심사) |

## 배운 것

- RESTful API 설계와 문서화, 통합 테스트 자동화
- 정산·배치 등 **돈과 데이터 정합성**이 중요한 시스템 감각
- 앱스토어/플레이스토어 배포와 플랫폼 정책 대응
